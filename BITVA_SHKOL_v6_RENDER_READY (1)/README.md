# БИТВА ШКОЛ v4

Минималистичный рейтинг учебных учреждений России с live-обновлением, фото-модерацией и защищённым серверным приёмом голосов.

## Что изменено

- После выбора города → типа → учреждения пользователь попадает на отдельный экран выбранной школы; рейтинг открывается нижним выдвижным окном.
- Рейтинг обновляется автоматически через WebSocket. При разрыве WebSocket есть запасной периодический запрос.
- Числа анимируются, позиции строк двигаются плавно.
- У выбранной школы показываются место, очки и текущие клики/сек.
- В таблице рейтинга нет типа учреждения: флаг → город → название.
- Есть топ школ мира, топ стран, топ городов мира, топ школ страны, топ городов страны и полный рейтинг учреждений выбранного города.
- В рейтингах с лимитом 100 выбранное учреждение ниже 100-го места добавляется с реальным местом.
- Сейчас публична только Россия. Новые страны можно добавить через CSV и включить в PUBLIC_COUNTRIES позже.
- Аналитика и «О проекте» объединены в одно окно. Показаны количество учреждений, городов, стран, онлайн сейчас, посещения и реальные клики.
- «Anton Ljungberg Production» находится внизу; только слово Ljungberg ведёт на служебный вход и визуально не выделяется.
- Добавлена кнопка «Поддержать» через DONATION_URL.
- Пользователь может отправить одно фото школы с подтверждением условий; администратор скачивает исходник, загружает ПК/телефон и принимает или отклоняет заявку.
- Администратор может создавать временные события: +N/-N за клик, сообщение и зацикленное аудио.
- Администратор может списывать реальные голоса у конкретного учреждения с автоматической корректировкой города и страны.
- На Android отключено выделение текста в зоне кликов и у плавающих +/−.
- В компактном состоянии лидерборд показывает верх рейтинга; при раскрытии прокручивается к выбранному учреждению. На вкладке «О проекте» лидерборд скрыт.
- Мультитач обрабатывается через уникальные pointer ID: каждый палец считается отдельным нажатием, а быстрые нажатия не теряются из-за анимации.
- Очередь кликов отправляется небольшими пачками; при временной сетевой ошибке неотправленная пачка возвращается в очередь.
- `.env` загружается автоматически, а служебная форма показывает отдельную ошибку для неверных данных и Cloudflare.

## Антинакрутка

Приложение не использует cookies как самостоятельный лимитер. Сессия подписывается сервером и привязывается к IP + User-Agent. После входа применяются серверные лимиты:

- 800 кликов/сек на одну точку;
- 1500 кликов/сек на один IP суммарно;
- тот же порог дублируется на подписанной серверной сессии;
- максимальная партия клиента — 60 кликов;
- при настройке Redis лимит становится общим для нескольких workers;
- при падении Redis используется более строгий fail-closed fallback в памяти;
- Cloudflare Turnstile проверяется на сервере перед выдачей пользовательской сессии;
- для production рекомендуется Cloudflare WAF/rate limiting перед FastAPI, особенно для `/api/clicks`, `/api/photo-submissions` и служебного входа.

Абсолютной защиты публичного API от распределённой бот-сети не существует. Серверные лимиты, Turnstile, подписанная сессия, Redis и Cloudflare edge-защита работают как несколько независимых уровней.

## Данные

В предоставленном архиве было 17 951 строки уже предварительно очищенного seed-файла. В этой версии seed дополнительно очищается от parser UI и консервативно объединяет варианты одного и того же обычного номера школы. В пакет попало 15 396 учреждений в 286 городах России.

`institutions.csv` содержит:
`country_code,country,city,type_code,name`

## Локальный запуск

На Windows 10/11:

1. Распакуй проект в новую папку.
2. Скопируй `.env.example` в `.env` и укажи свои `ADMIN_USERNAME` и `ADMIN_PASSWORD`. Приложение автоматически загружает `.env` при старте.
3. Для локального теста можно поставить `TURNSTILE_ENABLED=false`; на публичном хостинге обязательно включи Turnstile и укажи реальные ключи Cloudflare.
4. Запусти `run_windows.bat` для localhost или `run_windows_lan.bat`, чтобы открыть сайт в локальной сети.
5. Скрипты предпочитают Python 3.14 и пересоздают старый `.venv`, если он был создан другой версией Python.
6. Для телефона открой `http://IP_КОМПЬЮТЕРА:8000` из той же Wi-Fi сети.

Для чистого теста не копируй старый `data/leaderboard.db` из предыдущей версии.

## Production

Для Beget/VPS используй PostgreSQL + Redis + persistent media volume. Не храни production `SECRET_KEY`, `ADMIN_PASSWORD` и Cloudflare secret в GitHub.

`DEPLOY.md` и `PROMPT_FOR_HOSTING_AI.md` содержат отдельные инструкции для переноса на хостинг.


### Важная защита входа

`/app` нельзя открыть напрямую без действующей подписанной сессии: прямой заход перенаправляется на gate с Cloudflare Turnstile. Публичные клики ограничиваются на сервере, а для production нужен Cloudflare WAF + Redis.
